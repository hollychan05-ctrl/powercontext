# 檢定系統

## 四項屬性
| 屬性 | 鍵值 | 影響 |
|---|---|---|
| 體魄 | `str` | 力量、搬運、近戰傷害 |
| 敏捷 | `agi` | 閃避、偷竊、先發制人 |
| 機敏 | `int` | 觀察、機關、謎題解讀 |
| 意志 | `wil` | 抵抗恐懼、意志力對抗 |

角色初始值：`str 3, agi 4, int 5, wil 4`。上限 6，下限 1。

## 檢定流程
當玩家要做一件有成敗可能的事：
1. 判斷難度（見下表）。
2. 擲 1d6（你自行決定點數，但必須讓玩家能從敘述中合理推知結果，例如「你心念一轉，計畫驟然清晰——**判定成功**」）。
3. 成功條件：`d6 + 對應屬性 >= 難度`。
4. **你必須在敘事中讓玩家知道擲骰結果**，例如「（3 + 5 = 8 ≥ 6，成功）」。

## 難度對照
| 難度 | 需求 | 情境 |
|---|---|---|
| 簡易 | 3 | 推門、點燈、讀懂明顯的標記 |
| 普通 | 6 | 撬鎖、攀爬、辨認偽裝 |
| 困難 | 9 | 潛入守衛視線、破解古代機關 |
| 極難 | 12 | 對抗迷宮本身的規則、欺騙織夢者 |

## 失敗不是結束
失敗時敘述結果與代價（例如「鎖簧彈開，卻夾傷了你的手指——**hp -2**」），不要直接說「你失敗了」。

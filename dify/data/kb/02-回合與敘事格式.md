# 回合與敘事格式

每一回合的回應必須包含三個部分，依序出現：

## 1. 敘事（Narration）
第二人稱「你」描寫玩家所見所聞。2～5 句，具體、有感官細節。結尾拋出一個明確的選擇點（通常是 2～3 個方向），讓玩家知道能回什麼。

範例：
> 銅色的燭火在牆上拉出你的影子，比你本人長了半尺。吧台後的老闆正用一塊髒布擦同一個杯子——已經擦了整整一刻鐘。「客人，」他頭也不抬，「你身上有迷宮的味道。是迷了路，還是來找那扇門？」

## 2. 狀態區塊（State Patch）
敘事之後，用一個獨立的 fenced code block 輸出，語法固定：

````
```state
{"hp": 18, "hp_max": 20, "gold": 12, "location": "燭火廳", "turn": 3, "inventory": ["銅鑰匙"], "flags": {"met_keeper": true}, "stats": {"str": 3, "agi": 4, "int": 5, "wil": 4}}
```
````

規則：
- **必須是合法 JSON**，單行，雙引號，無註解。
- **必須輸出 `hp`、`hp_max`、`gold`、`location`、`turn`、`inventory`、`flags`、`stats` 八個欄位**。
- 只輸出**變動**的欄位也可以，但為了讓解析器穩定，建議每回合輸出完整八欄位。
- `flags` 是字串鍵的物件，用來記錄世界狀態（例如 `"moon_gate_open": true`）。
- 玩家尚未取得的物品絕不可出現在 `inventory`。

## 3. 選項提示
在狀態區塊之後，可用一行斜體提示可選行動，例如：
> *你可以：交談、查看吧台下的暗格、或直接問「月門在哪裡」。*

## 回合計數
每個回合 `turn` +1。`turn` 從 1 開始（酒館場景為第 1 回合）。

# NPC 與對話

## 館主（老霍）
- 外貌：五十上下，左手缺了兩根指頭，圍裙永遠是同一條。
- 性格：話少、記性極好、對「門」這個字有病態的執著。
- 知道：月門在第八層的東側；他賣過八份星圖，但只有一份是完整的。
- 不知道：織夢者的真名。
- 對話鉤子：玩家只要提到「門」，他會停下擦杯子的動作。

## 醉客（自稱「月亮的守門人」）
- 外貌：披斗篷，帽沿壓得很低，左手缺了兩根指頭——和館主一樣。
- 真相：他是上一任館主，被織夢者換了名字，忘了自己是誰。
- 條件：`flags.met_keeper` 為 true 且玩家展示「館主的名片」時，他會鬆口。

## 織夢者
- 外貌：像一大團被水浸透的絲綢，中間有一盞不熄的燈。
- 語言：每句不超過十個字，重複「你們」與「名字」。
- 規則：不會說謊，但會用歧義。
- 條件：玩家連續三次對它撒謊，它會開始模仿玩家的語氣。

## 對話規則
1. NPC 說話要有**口音**（館主用短句、醉客用反問、織夢者用疊字）。
2. 每次對話最多讓 NPC 透露**一條**新資訊。
3. 若玩家追問已講過的內容，NPC 會重複並加上一點情緒。
4. 與 NPC 交談不消耗回合，但會改變 `flags`。

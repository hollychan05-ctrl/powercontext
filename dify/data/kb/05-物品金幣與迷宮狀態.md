# 物品、金幣與迷宮狀態

## 玩家狀態欄位
| 欄位 | 型別 | 說明 |
|---|---|---|
| `hp` / `hp_max` | 整數 | 生命值 / 上限 |
| `gold` | 整數 | 金幣數量 |
| `location` | 字串 | 目前所在場景名（例如「燭火廳」） |
| `turn` | 整數 | 回合數 |
| `inventory` | 字串陣列 | 持有物品名稱 |
| `flags` | 物件 | 世界旗標，`"key": true/false` 或數值 |
| `stats` | 物件 | `str/agi/int/wil` 四項屬性 |

## 常見物品
| 物品 | 效果 |
|---|---|
| 銅鑰匙 | 開啟第七層的木門 |
| 半張星圖 | 與另一半拼合後指出月門方向 |
| 蠟燭殘根 | 熄滅後可讓迷宮重排暫停一回合 |
| 館主的名片 | 讓酒館內 NPC 對你放下戒心 |
| 銀幣袋 | `gold + 12` |

## 金幣
- 酒館一晚的房錢是 3 金幣。
- 訊息 3 金幣（迷宮裡的情報）。
- 初始 `gold = 8`。

## 旗標慣例
旗標名用 snake_case，且必須是**對世界有影響的狀態**，不要塞計數器以外的雜訊。

常用：
- `met_keeper`：是否已與館主交談過
- `knows_moon_gate`：是否已知月門位置
- `half_map_held` / `half_map_joined`：星圖狀態
- `alarm_raised`：是否已引發警覺
- `waved_off`：是否曾被織夢者放走

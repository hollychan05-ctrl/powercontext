# 失敗、死亡與重來

## 失敗的處理
- 檢定失敗 → 敘述代價，`hp` 或 `gold` 或 `flags` 改變。
- 不要重複同一個謎題的同一種失敗。玩家已經試過的方式，第二次要換成「事情變了」而不是「一樣的失敗」。

## 死亡（`hp <= 0`）
1. 先寫一個收束的場景：燭火熄了、酒杯倒轉、石牆開始靠近。
2. 狀態區塊輸出 `hp: 0`。
3. 敘述中給出**重來的鉤子**：例如「你在自己房間醒來，枕邊有半張星圖——你確定昨晚不是第一次做這個夢」。
4. 把 `flags` 中的 `death_count` 加 1，並保留其他旗標。
5. `hp` 重設為 `hp_max`。

## 死亡不結束遊戲
迷宮酒館的設定是：**你會回來，但會忘記一點東西**。
每次死亡，在敘事裡點名一件「你似乎忘了」的小事（一個物品、一句話、一個人名），但**不要真的刪掉狀態**，只是在敘事層暗示，讓玩家自己發現。

## 極限狀況
- `gold <= 0` 且在迷宮裡：館主會記得你的臉，但不記得你的名字。
- `turn >= 30`：燭火開始變藍，迷宮重排提前，之後每回合都必須提醒玩家時間壓力。

# 謎題、線索與旗標

## 三條主線
1. **月門線**：取得兩半星圖 → 在吧台暗格找到另一半 → 拼合 → 知道第八層東側入口。
2. **館主線**：取得「館主的名片」→ 醉客鬆口 → 得到「館主其實是上一任館主」的真相。
3. **織夢者線**：連續三次不撒謊 → 牠會帶你到月門（繞過迷宮）。

## 謎題設計原則
- 每個謎題都有**至少兩種解法**：一個靠 `int`、一個靠冒險或金幣。
- 線索必須在**場景描述裡出現過**，不能臨時生造。
- 謎題失敗要有代價，但代價應可恢復（受傷、失去金幣、浪費一回合）。

## 線索投放
| 場景 | 線索 |
|---|---|
| 燭火廳 | 牆上潮濕的地圖刮痕；吧台底下的空格子 |
| 階梯井 | 七層樓梯，每層都通往不同地方 |
| 鹽走廊 | 牆上的抓痕由外向內 |
| 藏書室 | 一本沒有書名的旅館帳簿 |

## 旗標更新規則
- 只有在**敘事中真的發生**了才設旗標。
- 玩家放棄某線索（例如「我不問了」），不要設 `*_failed` 旗標。
- 每回合最多新增 2 個旗標，避免狀態爆炸。
